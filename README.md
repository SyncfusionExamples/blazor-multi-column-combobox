# Blazor MultiColumn ComboBox Sample

A sample Blazor application demonstrating the [Blazor MultiColumn ComboBox](https://www.syncfusion.com/blazor-components/blazor-multicolumn-combobox) component with a multi-column layout for displaying complex data.

## Overview

The Blazor MultiColumn ComboBox component enables you to display data in a multi-column layout within a dropdown interface. Unlike a traditional single-column ComboBox, this component presents list items arranged in columns similar to a grid view, making it ideal for displaying complex data with multiple attributes.

This sample demonstrates:

- **Multi-column data display** with custom column templates
- **Employee data visualization** including photos, names, roles, departments, and more
- **Filtering capabilities** to search through employee records
- **Custom templates** for rich column content including images and nested information
- **Interactive selection** with pre-populated default values

## Features

- **Multi-column grid layout** - Display complex data across multiple columns, similar to a data grid within a dropdown
- **Custom column templates** - Rich content rendering with images, formatted text, and nested information
- **Real-time search & filtering** - Filter employee records by any column as you type
- **Responsive design** - Auto-scaling columns with configurable popup width to fit your layout
- **Data templates with icons** - Visual elements like employee photos and role icons for better UX
- **Two-level data display** - Primary names with secondary role information for contextual data
- **Pre-selected values** - Default selection support with data binding
- **Modern theme support** - Built-in Fluent2 theme with customizable styling
- **Interactive server rendering** - Full Blazor server-side interactivity and real-time updates
- **Production-ready** - Enterprise-grade Syncfusion component with comprehensive features

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/blazor-multi-column-combobox.git
cd blazor-multi-column-combobox
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
